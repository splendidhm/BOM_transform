# BOM Transform

구 ERP BOM RAW 파일을 신 ERP 엑셀 입력 양식으로 일괄 변환하는 Windows PyQt5 도구입니다.

`BOM_변환기/실행.bat`을 실행한 뒤 숫자 제품코드 이름의 RAW 파일 또는 폴더를 끌어 놓고 **변환 시작**을 누릅니다. 완료 파일은 `<제품코드> 완료.xlsx`로 저장됩니다.

사용 방법과 지원 형식은 [BOM_변환기 사용안내](BOM_변환기/README.md), 개발 규칙은 [AGENTS.md](AGENTS.md), 구현 상태와 인수인계 내용은 [HANDOFF.md](HANDOFF.md)를 확인하세요.
